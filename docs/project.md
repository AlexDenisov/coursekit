# Project specifics

This course's answers to the "Project specifics" questions at the end of
[PLAYBOOK.md](../PLAYBOOK.md). The playbook stays generic; everything
particular to this course goes here. Filled in by the agent during
bootstrap (see [AGENTS.md](../AGENTS.md)) and kept up to date.

- **Topic / end goal:** how Redis works, learned by building it. Main goal:
  `server/mini_redis`, a single-threaded event-loop server that `redis-cli`
  and `redis-benchmark` use unchanged, with strings, expiry, lists, hashes,
  sets, KEYS/SCAN, and a compatibility suite recorded from real Redis.
  Advanced tracks (internals, durability, messaging) are planned beyond that.
- **Learner:** uses Redis from the outside; new to its internals, to
  systems programming (sockets, event loops, fork) and to the underlying data
  structures, so start from first principles. 5–10 h/week. macOS on Apple
  silicon (kqueue, not epoll).
- **Tracks (goals) and milestones (★):**
  - Protocol → ★ `server/hello_cli` (basic)
  - Event loop → ★ `server/event_server` (intermediate)
  - Keyspace → ★ `server/mini_redis` (intermediate, the main goal)
  - Internals → ★ `server/lean_redis` (advanced)
  - Durability → ★ `server/durable_redis` (advanced)
  - Messaging → ★ `server/messaging_redis` (advanced)
- **Levels:** basic / intermediate / advanced (the template's default).
  Basic = talk to redis-cli; intermediate = usable mini Redis; advanced =
  everything after.
- **Language, toolchain, and deviations from PLAYBOOK §11–12:** C++20, Bazel
  + hermetic clang, GoogleTest (the `starters/cpp-bazel` stack). Event loop
  uses kqueue only (macOS); an epoll backend is a possible side track. RESP2
  only (RESP3 is a future topic).
- **Namespace / check macro prefix:** `rd` / `RD_` (Bazel module `rd`).
- **Oracle(s):** every expected value comes from one of these, all checked in
  under `tools/` and re-runnable (`brew install redis` gives Redis 8.10.3, which
  recorded everything):
  - `redis_reference.py`: runs `tools/cases/*.txt` against a throwaway
    `redis-server` and prints each reply byte for byte; `--inc` builds the
    milestone compatibility tables (`server/*/compat_cases.inc`).
  - `glob_reference.py`: `KEYS <pattern>` over fixed subjects (db/glob's table).
  - `crc64_reference.py`: the CRC definition, cross-checked with DUMP trailers.
  - `blob_reference.py`: intset and listpack bytes dug out of DUMP payloads.
  - `rdb_reference.py`: real `dump.rdb` files (`persist/rdb_reader/testdata/`).
  - `aof_reference.py`: how Redis logs commands to its AOF.
  - `messaging_reference.py`: multi-client exchanges (pub/sub, MULTI/WATCH, BLPOP).
  - Brute-force models (`std::unordered_map`, `std::set`, ...) for the data
    structures; `std::to_string` / `std::to_chars` for number formatting.
  - Real clients as end-to-end oracles, in `manual` tests that skip when Redis
    isn't installed: `redis-cli`, `redis-benchmark`, a real `redis-server`
    loading our RDB, and a real primary our replica follows.
- **Real data (download scripts, env vars):** none. Fixtures are generated by
  the scripts above and checked in.
- **Redis 8 facts the course relies on:** RDB version 15; `hash-max-listpack-entries`
  512 (not 128 as in Redis 7), the other thresholds 128/512/64; `KEYS *` skips the
  matcher; `SET ... GET GET` is accepted.
- **Domains (directories):** `resp/`, `net/`, `cmd/`, `ds/`, `db/`,
  `persist/`, `repl/`, `msg/`, `server/`.
- **Given vs built by the learner:** every exercise is built by the learner;
  stubs keep small given parts (the `Fd` RAII wrapper, `CommandTable::add`,
  `parse_policy`/`is_denyoom`, LeanRedis's CONFIG command, the server
  `main.cc` files). Shared infrastructure in `common/`: checks, RNG, clocks
  (`SystemClock`, `FakeClock`), and test-only helpers that never call
  exercise code: `test_client.h` (a RESP client), `transcript.h` (replays
  recorded transcripts, order-insensitive where Redis is).
- **Branch:** the course's main branch is `redis` (treated as `main`
  everywhere in AGENTS.md). Solutions on the orphan branch `solutions`.
- **License:** MIT for both the template and the learner's work (the existing
  `LICENSE` covers everything).
